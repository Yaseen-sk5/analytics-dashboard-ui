About Me

Hi, I'm Shaik Yaseen, a Java Developer with over four years of experience building enterprise healthcare applications. I specialize in Spring Boot microservices, RESTful API development, and SQL, and I enjoy turning complex, legacy systems into clean, scalable, and reliable backend platforms.

I currently work at Entomo Labs, where I lead backend modernization for healthcare apps using Java 21 and Spring Boot. This includes building JWT-secured APIs, containerizing services with Docker, and implementing HL7-FHIR MedicationRequest APIs that make healthcare data easier to share between systems. Before that, I spent over three years at Dedalus Healthcare, where I built Java web applications with Spring and Hibernate/JPA, migrated a legacy codebase from Java 8 to 17, and set up CI/CD pipelines with Jenkins.

I hold a Master of Computer Applications from SRM Institute of Science and Technology and a B.Sc. in Computer Science. I work comfortably in Agile teams, and I care about writing well-tested code with JUnit and Mockito, documenting APIs with Swagger, and delivering software that people can depend on. I'm always looking to learn new technologies and take on challenging problems. If you'd like to collaborate or just connect, feel free to reach out on LinkedIn or GitHub.
